# Minecraft in Terminal

This is fork of the minecraft in terminal project. But ported to linux. And added full coloring.

## Usage

Just run `run,sh`, it will make a `venv` and run the Python script.

### Manually

```
python3 -m venv .venv

source .venv/bin/activate

pip install Pillow python-xlib

python main.py
```
